## План

1. Создать Buddy, Wiki, Tracker и Ticket: модули, БД, Compose, OIDC.
2. Tracker: задачи, дедлайны, прогресс, наставники и API.
3. Ticket: вопросы наставнику, списки тикетов, идемпотентность.
4. Wiki: документы, права доступа, гибридный поиск с pgvector.
5. Buddy: диалоги, модель, MCP-инструменты и подтверждение действий.
6. SSE: поток ответов, восстановление без дублей, ошибки и повтор.
7. React: интерфейсы четырёх сервисов.
8. Настроить межсервисные API-ключи, права и повторяемые демо-данные.
