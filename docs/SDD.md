# SDD

- Go HTTP API: handler → service → repository → PostgreSQL/pgvector.
- Ollama: qwen3.5:4b для чата, embeddinggemma:300m для поиска по Markdown из knowledge-base/.
- Buddy вызывает MCP-инструменты и передаёт текст и карточки через SSE. История приходит в запросе и не сохраняется.
- Создание задач/тикетов и завершение задач выполняют отдельные POST после нажатия кнопки.
- Пользователь выбирается cookie demo_user; доступ определяется ролью, командой и текущим назначением ментора.
- Миграции, демо-сиды и индексация запускаются отдельными командами. Тесты работают без внешних сервисов.
