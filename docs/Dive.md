# Dive

Стажёру нужно быстро находить внутренние документы, видеть свои задачи и обращаться к ментору.
AI Buddy объединяет поиск по базе знаний, карточки задач и тикетов в чате.
Стажёр подтверждает действия кнопкой; ментор просматривает задачи и тикеты своих стажёров.
Цель — сократить время поиска информации и рутинные вопросы ментору.
