# Пошаговый рефакторинг Buddy AI

Перед работой по рефакторингу прочитай [docs/REFACTORING.md](docs/REFACTORING.md).
Там зафиксированы требования пользователя, порядок совместной работы и состояние перехода.

- Пользователь управляет изменениями вплоть до отдельных функций. Выполняй текущую
  команду и необходимые для неё сопутствующие изменения; не начинай следующую фичу сам.
- Если пользователь просит обсудить решение, обсуждай без изменения кода.
- Не добавляй неописанные возможности. Старый код и прежняя документация не являются
  требованиями к новому бэкенду.
- Структуру нового кода и упрощение поведения согласовывай по ходу выбранной фичи.
  Не создавай заранее полный каркас или слои для будущих возможностей.
- `backend-ai/` — прежняя реализация для изучения и сравнения. Не рефактори её
  автоматически и не копируй целиком в новый `backend/`. Изменяй её только по
  соответствующей команде пользователя.
- После законченного шага обнови состояние в инструкции и кратко сообщи, что
  изменено, что проверено и какие решения остались открытыми.

Последующие явные указания пользователя имеют приоритет над этой инструкцией.
