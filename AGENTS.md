# Работа над AI Buddy

- Выполняй текущую команду пользователя и необходимые сопутствующие изменения;
  не начинай следующую фичу самостоятельно.
- Если пользователь просит обсудить решение, обсуждай без изменения кода.
- Не добавляй неописанные возможности. Структуру нового кода и упрощение поведения
  согласовывай по ходу выбранной фичи; не создавай слои для будущих возможностей.
- Системный промпт держи коротким, без длинных примеров и повторов.
- В Go разделяй логические этапы пустыми строками, ориентируйся на 120 символов.
  Типы объявляй отдельно; импорты группируй: стандартные, backend, сторонние.
  SQL оставляй многострочным в методах репозиториев.
- После законченного шага кратко сообщи, что изменено, что проверено
  и какие решения остались открытыми. Документацию держи краткой и актуальной.
- Сообщения коммитов формируй с помощью скилла caveman-commit.

Последующие явные указания пользователя имеют приоритет над этой инструкцией.
